Hostinger par Next.js + MySQL website ko live karne ka mukammal **Step-by-Step Guide**:

---

### Step 1: Hostinger par MySQL Database Banayein

1. **Hostinger hPanel** mein login karein.
2. **Databases** ➔ **MySQL Databases** section par jayein.
3. Naya database create karein:
   - **Database Name:** e.g., `u123456789_saffron`
   - **Username:** e.g., `u123456789_dbuser`
   - **Password:** e.g., `StrongPassword123#`
4. **Create** button dabayein. Details ko note kar lein.

---

### Step 2: Production `.env` File Configure Karein

Apne server / Hostinger par `.env` file mein `DATABASE_URL` is format mein set karein:

```env
# Server Port
PORT=3000

# Hostinger MySQL Database URL Format:
# mysql://USERNAME:PASSWORD@localhost:3306/DATABASE_NAME
DATABASE_URL="mysql://u123456789_dbuser:StrongPassword123%23@localhost:3306/u123456789_saffron"

# Production Domain URLs
NEXT_PUBLIC_SITE_URL="https://yourdomain.com"
NEXT_PUBLIC_WHATSAPP_NUMBER="923331113551"
NEXT_PUBLIC_PHONE_NUMBER="0333 1113551"

# Security Secret
APP_SECRET="saffron-city-executive-secret-key-2026-secure"
```

> [!TIP]
> Agar password mein special characters (jaise `#`, `@`, `%`) hon to unhe URL-encoded likhein (jaise `#` ki jagah `%23`).

---

### Step 3: Project Files Upload Karein

#### Option A: Hostinger VPS (Recommended for Next.js)
SSH terminal ke zariye server se connect karein aur repository clone karein:
```bash
git clone <your-repo-url> /var/www/saffron-city
cd /var/www/saffron-city
```

#### Option B: Hostinger Cloud / Node.js Web Hosting
- Local project se `.next`, `node_modules` ko chhor kar baki files ka **Zip** banayein.
- Hostinger **File Manager** mein upload karke extract karein.

---

### Step 4: Dependencies Install & Database Tables Generate Karein

Terminal / SSH mein project folder ke andar yeh commands chalayein:

```bash
# 1. Packages install karein
npm install

# 2. Prisma Client generate karein
npx prisma generate

# 3. Database tables create karein (Hostinger MySQL par schema push hoga)
npx prisma db push

# 4. Super Admin user create karne ke liye (ubaidnasir401@gmail.com)
npx tsx prisma/seed.ts
```

---

### Step 5: Next.js Production Build Banayein

```bash
npm run build
```

---

### Step 6: Website ko 24/7 Background mein Live Chalana (PM2)

Next.js app ko background process ke taur par run karne ke liye:

```bash
# PM2 install karein (agar pehle se nahi hai)
npm install -g pm2

# Next.js app start karein
pm2 start npm --name "saffron-city" -- start

# Server restart par automatically on rakhne ke liye:
pm2 save
pm2 startup
```

---

### Step 7: Domain & SSL Setup
1. Hostinger hPanel mein **Domain Management** / **Nginx Reverse Proxy** se port `3000` ko apne domain (`yourdomain.com`) par map karein.
2. Hostinger **SSL** tab se free Let's Encrypt SSL activate karein.
3. Website `https://yourdomain.com` aur Super Admin Dashboard `https://yourdomain.com/dashboard` par live chalegi.
